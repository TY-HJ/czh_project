# 项目结构说明

> 更新日期：2026-10-20（S8 完成后）。配合《代码检查报告》和两份需求文档一起看。

## 一、总体架构

前后端分离：Vue3 (5173) → axios 请求 `/api/**` → Vite 开发代理 → Spring Boot (8080) → MyBatis-Plus → MySQL 8 (repair_system 库)。认证用 JWT（登录后所有请求带 `Authorization: Bearer <token>`）。

```
浏览器 ──► 前端 Vue3 (5173, Vite 代理 /api 和 /uploads)
              │
              ▼
       Spring Boot (8080)
       SecurityFilter(JWT校验) → Controller(角色鉴权) → Service(业务+状态机) → Mapper → MySQL
              │
              └── /uploads/** 直接映射 backend/uploads/ 目录（报修照片）
```

## 三、后端 8 个 Controller 速查

| Controller | 路径前缀 | 权限 | 职责 |
|---|---|---|---|
| AuthController | /api/auth | 公开 | 登录、住户注册、获取当前用户 |
| OrderController | /api/orders | 按方法分角色 | **工单全部状态流转**（提交/派单/完成/验收/撤销/关闭/催办）+ 详情/日志 |
| UserController | /api/users | ADMIN | 用户分页/增改/启停/删除 |
| DictController | /api/dict | 查询公开、改删 ADMIN | 报修类型 + 楼栋单元房间字典 |
| MessageController | /api/messages | 登录用户 | 站内消息列表/未读数/已读 |
| NoticeController | /api/notices | 查公开、增删改 ADMIN | 公告 |
| StatsController | /api/stats | ADMIN | 指标卡/类型分布/月趋势/维修工排行 |
| FileController | /api/files | 登录用户 | 图片上传（存 backend/uploads） |

## 四、改东西去哪里找（常见场景）

| 想改什么 | 去哪里 |
|---|---|
| 工单状态流转规则 | `service/OrderService.java`（每个方法开头 checkStatus 就是状态机闸门） |
| 接口权限（谁能调） | 对应 Controller 方法上的 `@PreAuthorize("hasRole('...')")` |
| 前端页面菜单/路由限制 | `router/index.js` 的 meta.roles + `layout/Layout.vue` 的 menus |
| 登录 token 有效期/密钥 | `application.yml` 的 jwt 节点 |
| 超时提醒规则（24h/48h） | `task/OrderTimeoutTask.java` |
| 演示账号/密码提示 | `sql/init.sql` 末尾 + `config/demo.js` |
| 新增一张表/接口 | entity → mapper → service → controller 四层各加一个（照现有抄） |
